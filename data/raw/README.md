# Local experimental data

Place authorized `Day1.xlsx`, `Day2.xlsx`, `Day3.xlsx`, and `Day4.xlsx` here to
run the experimental configurations. Human records are not included in this
public code package and are excluded from Git by default.

See [the input format](../../docs/DATA_FORMAT.md) for worksheet names and columns.
For the included software demonstration, use `data/synthetic/` with
`configs/synthetic_smoke.yaml` instead.
